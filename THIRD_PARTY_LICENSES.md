# Third-Party Data Licenses and Attribution

This repository includes benchmark resources derived from publicly available third-party datasets. This document records the upstream source for each dataset, the license or reuse terms identified during review, and the authoritative policy or license link used for verification.

The goal is transparency for anyone using, reviewing, or redistributing the benchmark artifacts in this repository.

## What This File Covers

- Licenses used by the third-party datasets referenced by [README.md](README.md).

## Important Notes

- This file covers third-party data terms only. It does not define the software license for this repository.
- The original source provider and its published terms remain the authoritative source.
- Upstream terms may change over time. Anyone reusing or redistributing the data should verify the current source terms before release.
- Derived artifacts in this repository should be used in a way that remains consistent with the upstream terms summarized below.
- This document is provided for convenience and transparency and is not legal advice.
